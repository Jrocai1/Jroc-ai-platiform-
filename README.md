# J-ROC AI Platform

This repository is the platform-level home for the J-ROC AI ecosystem blueprint and implementation instructions.

## Start here
1. Read [the master blueprint](docs/JROC-AI-MASTER-BLUEPRINT.md).
2. Give [the master build prompt](docs/JROC-AI-MASTER-BUILD-PROMPT.md) to your VS Code coding agent.
3. Follow [repository Copilot instructions](.github/copilot-instructions.md).
4. Use the [LLM Gateway specification](docs/LLM-GATEWAY-SPECIFICATION.md) for all AI model routing.
5. Use [acceptance and status rules](docs/ACCEPTANCE-AND-STATUS.md) to report progress honestly.

## Important
This repository starts with architecture and implementation instructions. These documents do not themselves constitute a completed or tested platform. Implementation status must be supported by actual code, tests, and deployment evidence.
